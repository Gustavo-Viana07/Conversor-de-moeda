# Conversor-de-moeda
O Conversor de Moedas é uma aplicação web desenvolvida para realizar a conversão de valores entre diferentes moedas de forma rápida, simples e precisa.  O sistema utiliza a Exchange Rate API, que fornece taxas de câmbio em tempo real, garantindo que os valores apresentados estejam sempre atualizados de acordo com o mercado financeiro.
